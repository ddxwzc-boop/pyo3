Add `PyDictMethods::iter_extract` and the `ExtractingDictIterator` iterator, which iterate over dictionary (key, value) pairs converting each to `(K, V)` without taking a reference count per pair, with the same safe-by-construction design as `PyListMethods::iter_extract`: exact native members are read by direct field reads, and both members of a pair are pinned before either conversion starts, so reentrant Python code (e.g. from a custom `__index__` key) cannot free the pair's not-yet-converted member. The guards and panic messages match the owned `iter()` (panicking when the dictionary changes size or its key set changes during iteration). The pre-existing internal `BorrowedDictIter` used by keyword-argument parsing is unchanged.
