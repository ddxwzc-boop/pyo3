Add `PyListMethods::iter_extract` and the `ExtractingListIterator` iterator, which iterate over list items converting each to `T` (`i8`-`i64`, `u8`-`u64`, `isize`, `usize`, `f32`, `f64`) without taking a reference count per item. Items which are exact native objects (`int`, `float`) are read by direct field reads inside the iterator step; every other item (subclasses, custom `__index__`/`__float__` implementors) is pinned — its reference count incremented — before the ordinary extraction machinery runs. This is a safe API: no borrowed pointer ever escapes the iterator, and Python code which reenters during a conversion (e.g. from `__index__`) cannot free the item being converted. Iteration order, the `min(initial_length, current_length)` bound, and error behavior match `iter()` composed with `extract`. Under the limited API the fast path is unavailable and every item is pinned (correct, without the zero-refcount benefit).
