Avoid taking a reference count on the classinfo when constructing `CastError` / `CastIntoError` for process-global static type objects (the builtin types such as `str`, `list`, `int`, ...): the classinfo is now held as a borrow for those, eliminating the `Py_INCREF` / `Py_DECREF` pair on cast-failure paths. Error messages and `PyErr` conversion are unchanged; manual `PyTypeCheck` implementations (e.g. weakref's tuple classinfo) and heap types keep the previous owned behavior.
