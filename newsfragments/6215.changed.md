Reduced reference-counting traffic in sequence and mapping extraction.

``Vec<T>``, ``HashMap<K, V>`` and ``BTreeMap<K, V>`` extraction from an exact
``list`` / ``dict`` now iterates by borrowed (reference-free) access for
element types whose extraction cannot execute arbitrary Python code for the
shape of the actual elements (exact ``int`` / ``float`` / ``str``; anything
else - e.g. subclasses or objects defining ``__index__`` / ``__float__`` -
falls back to the original owned path for just that element).

This elides the two reference count updates per element/entry of the owned
path. On elements which run user code during extraction the mutation guards
(list length re-clamping, dict size-change panics) are unchanged.

The fast path is only compiled for non-``abi3`` builds.
